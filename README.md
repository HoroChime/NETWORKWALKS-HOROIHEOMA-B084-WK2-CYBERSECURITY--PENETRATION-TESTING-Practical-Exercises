## PROJECT OVERVIEW

This repository documents Week 2 practical cybersecurity exercises completed as part of the NetworkWalks Cybersecurity Internship.

The practical sessions focused on web reconnaissance, Open-Source Intelligence (OSINT) footprinting, DNS enumeration, domain information gathering and network discovery using Kali Linux and other security tools.

The exercises provided hands-on exposure to reconnaissance methodologies and practical security tools used during the information-gathering stage of penetration testing.

---

## TOOLS AND PRACTICAL EXERCISES

### 1. Kali Linux Reconnaissance Tools

| Tool | Purpose |
|---|---|
| WHOIS | Domain registration lookup |
| WhatWeb | Web technology fingerprinting |
| Nslookup | DNS resolution |
| cURL | HTTP response header inspection |
| WAFW00F | Web Application Firewall detection |
| DNSRecon | DNS enumeration |

**Practical activities:**
- Domain registration information lookup.
- Web technology fingerprinting.
- DNS resolution and information gathering.
- HTTP response header inspection.
- Web Application Firewall identification.

### 2. Maltego – Visual OSINT

**Version:** Maltego Graph Desktop 4.14.0

Maltego was installed and configured for visual OSINT investigations and relationship discovery.

**Practical activities:**
- Application installation and configuration.
- Domain entity creation.
- WHOIS-related entity discovery.
- Email transformation exploration.

### 3. theHarvester – OSINT Footprinting

Practical exercises covering:

- Email address discovery.
- Subdomain enumeration.
- Hostname identification.
- Public information gathering.

### 4. Google Hacking Database (GHDB)

Explored search-engine operators for identifying publicly indexed information, exposed directories and potentially sensitive documents.

The exercise provided an understanding of how advanced search operators can support security research and external exposure awareness.

### 5. Zenmap – Network Scanning

Practical exercises covering:

- Ping scan and host discovery.
- Active host identification.
- Port-state interpretation.
- Service identification.
- Network topology visualization.
