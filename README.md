PROJECT OVERVIEW

 TOOLS AND PRACTICAL EXERCISES

 Kali Linux Reconnaissance Tools 

| Tool | Purpose |
| WHOIS | Domain registration lookup |
| WhatWeb | Web technology fingerprinting |
| Nslookup | DNS resolution |
| cURL | HTTP response header inspection |
| WAFW00F | WAF detection |
| DNSRecon | DNS enumeration |

 Maltego – Visual OSINT

Version: Maltego Graph Desktop 4.14.0

Practical activities:
- Application installation and configuration.
- Domain entity creation.
- WHOIS-related entity discovery.
- Email transformation exploration.

theHarvester – OSINT Footprinting 

Practical exercises covering:
- Email address discovery.
- Subdomain enumeration.
- Hostname identification.
- Public information gathering.

Google Hacking Database (GHDB)

Explored search-engine operators for identifying publicly indexed information, exposed directories and potentially sensitive documents.

Zenmap – Network Scanning 

Practical exercises covering:
- Ping scan and host discovery.
- Active host identification.
- Port-state interpretation.
- Service identification.
- Network topology visualization.
